# Graip

Graip is a fork of [Cherri](https://github.com/x8rr/cherri), rebranded with a new name, a new default theme (midnight), and several bug fixes. The original Cherri project was itself a rebuild of Breeze.

### Links

- GitHub: https://github.com/debug-cli/cherri-vercel
- Upstream: https://github.com/x8rr/cherri

Every store listed in the Games menu ships in this repository (Classplay/UCP and
GN-Math). The Cloudflare Pages deploy intentionally uses the bundled GN-Math
store only, because the Classplay game files exceed Cloudflare Pages' asset limit.
